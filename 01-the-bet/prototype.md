# The Prototype Bet

## Prompt Used
```
Build me a web app prototype for an AI CoPilot product called Signal.

Who: Product Managers - role: Who gets their product feedback from multiple source and needs to act based on omnichannel feedbacks]
Core task: The AI should be able to get feedback from Salesforce tickets, Store Reviews, Customer Support calls, User feedback interviews, marketing, sales
First screen: A dashboard which gives a summary on the feedback, highlights and access to different sources input
AI moment: User clicks "Synthesize" (or drops in a batch of raw feedback/transcripts) → AI clusters themes, tags sentiment, and drafts an opportunity card for each cluster
Output: A ranked list of opportunity cards — each with a title, a synthesized "why," supporting quotes/evidence count, an estimated impact/effort tag, and a one-click "Add to roadmap" button

Clean UI. Dark theme. One page. No login.
```

## What I Built
<!-- One sentence: what does this prototype demonstrate? -->
Signal, an AI copilot that pulls a product's feedback for a Product Manager from six channels (Salesforce tickets, store reviews, support calls, user interviews, marketing, and sales) into one dashboard, then turns a "Synthesize" click into ranked, evidence-backed opportunity cards ready to push to the roadmap.

## AI Value Archetype
<!-- Automator / Copilot / Oracle / Creator / Orchestrator -->
Copilot — it doesn't decide what to build, it does the unpaid labor of reading and synthesizing scattered cross-channel feedback so the PM can review, weigh, and decide faster.

## The Bet in One Sentence
<!-- What you're building, for whom, why now -->
If PMs can see cross-channel feedback pre-clustered into ranked, evidence-backed opportunities instead of reading six raw feeds by hand, they'll catch real signal faster and ship roadmap decisions with better justification.

## Kill Criteria
<!-- When would you stop? What evidence would kill this bet? -->
If PMs don't trust the AI's clustering and sentiment tagging enough to act on it without re-reading all the source material themselves — i.e., it saves no real time — the bet is dead.
